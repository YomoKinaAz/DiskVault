DiskVault

Disk-image backup and bare-metal recovery for Windows ／ Windows 用ディスクイメージ バックアップ

  • Full / incremental image backups from VSS snapshots, deduplicated, zstd-compressed, optional AES-256 encryption
  • Schedules, e-mail notifications, local / USB / NAS destinations
  • File, volume and whole-disk (bare-metal) restore; WinPE recovery USB / ISO

Source code & documentation ・ Download ・ Support (Issues) ・ Privacy policy / プライバシーポリシー

Important / 重要: the installer is not code-signed yet. Turn off Smart App Control (Windows Security → App & browser control) before installing, or the DiskVault service cannot start at the end of the installation.
まだコード署名をしていないため、インストールの前に「Windows セキュリティ → アプリとブラウザーの制御」でスマート アプリ コントロールをオフにしてください。オンのままでは、インストールの最後にサービスを起動できません。
