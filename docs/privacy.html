DiskVault プライバシーポリシー

発行者: YomoKinaAz ／ 制定日: 2026年11月12日 ／ English

DiskVault（以下「本アプリ」）は、Windows のディスクイメージをバックアップ・復元するアプリです。本ポリシーは、本アプリが扱う情報とその取り扱いを説明します。

1. 収集する情報

本アプリは、利用者の個人情報や利用状況を発行者や第三者に送信しません。利用状況の統計（テレメトリ）、広告、利用者アカウント、発行者が運営するサーバーとの通信はありません。

2. PC 内に保存する情報

  • 設定・履歴・ログ：バックアップ ジョブの設定、実行履歴、ログを、この PC の %ProgramData%\DiskVault に保存します。管理者と SYSTEM だけが読めるようにしています。
  • パスワード：NAS・メールサーバー・暗号化のパスワードを保存する場合は、Windows のデータ保護機能（DPAPI）で暗号化して保存します。
  • バックアップデータ：利用者が指定した保存先（この PC のドライブ、USB ディスク、NAS など）にだけ書き込みます。暗号化を選ぶと AES-256 で暗号化します。バックアップには、対象ディスク上のファイル（個人のファイルを含むことがあります）がそのまま含まれます。

3. 外部との通信（利用者が設定した場合のみ）

  • NAS（共有フォルダ）：保存先に共有フォルダを指定した場合、その機器にバックアップデータを書き込みます。
  • メール通知：メール通知を有効にした場合、利用者が指定したメールサーバー（SMTP）を通じて、指定した宛先にバックアップ結果（ジョブ名、PC 名、日時、結果、エラー内容など）を送信します。
  • Windows ADK のダウンロード：回復メディアの作成で「インストール」を選んだ場合、Windows の winget を使って Microsoft から Windows ADK をダウンロードします。この通信には Microsoft のプライバシーに関する声明が適用されます。

これらの通信先は、すべて利用者が選んだ機器・サービス、または Microsoft です。発行者がその内容を受け取ることはありません。

4. 第三者への提供

発行者は利用者の情報を受け取らないため、第三者に提供・販売することはありません。Microsoft Store からのダウンロードや更新には、Microsoft のプライバシーに関する声明が適用されます。

5. 情報の削除

本アプリをアンインストールしたあと、%ProgramData%\DiskVault フォルダを削除すると、設定・履歴・ログが消えます。バックアップデータは保存先のフォルダを削除してください。

6. 子どもの利用

本アプリは子どもを対象としたものではなく、子どもの情報を意図して収集することはありません。

7. 本ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、制定日を改めます。

8. お問い合わせ

GitHub の Issues（https://github.com/YomoKinaAz/DiskVault/issues）からお問い合わせください。

DiskVault Privacy Policy

Publisher: YomoKinaAz / Effective: November 12, 2026

DiskVault (“the app”) backs up and restores Windows disk images. This policy explains what information the app handles and how.

1. Information we collect

The app does not send any personal information or usage data to the publisher or to third parties. There is no telemetry, no advertising, no user account, and no communication with servers operated by the publisher.

2. Information stored on your PC

  • Settings, history and logs are stored on your PC in %ProgramData%\DiskVault, readable only by Administrators and SYSTEM.
  • Passwords (NAS, mail server, backup encryption), if saved, are encrypted with the Windows Data Protection API (DPAPI).
  • Backup data is written only to the destination you choose (a local drive, USB disk or NAS). If you enable encryption, it is encrypted with AES-256. Backups contain the files on the disks you back up, which may include personal files.

3. Network communication (only when you configure it)

  • NAS / network shares: backup data is written to the share you specify.
  • E-mail notifications: if enabled, backup results (job name, PC name, time, status, error messages) are sent through the SMTP server you specify to the recipients you specify.
  • Windows ADK download: if you choose to install it when creating recovery media, the Windows ADK is downloaded from Microsoft using winget, subject to the Microsoft Privacy Statement.

All of these destinations are devices or services you choose, or Microsoft. The publisher never receives this data.

4. Sharing with third parties

The publisher does not receive your information and therefore does not share or sell it. Downloads and updates through the Microsoft Store are subject to the Microsoft Privacy Statement.

5. Deleting your information

After uninstalling the app, delete the %ProgramData%\DiskVault folder to remove settings, history and logs. Delete the backup folders at your destination to remove backup data.

6. Children

The app is not directed at children and does not knowingly collect information from children.

7. Changes to this policy

If this policy changes, this page will be updated with a new effective date.

8. Contact
